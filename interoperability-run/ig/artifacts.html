This page provides a list of the FHIR artifacts defined as part of this implementation guide.

Structures: Resource Profiles

These define constraints on FHIR resources for systems conforming to this implementation guide.

Interoperability Run - ECG

An ECG recording (e.g. single-lead from a smartwatch) taken during an Interoperability Run. The waveform is carried as SampledData in one component per lead, coded with ISO/IEEE 11073 MDC codes.
Interoperability Run - appointment

The scheduled Interoperability Run (or a preventive check-up slot around it) with the runner and the meeting location.
Interoperability Run - environmental conditions

Weather and water conditions at the course during an Interoperability Run: air temperature, relative humidity and, for swimmers, water temperature. The subject is the course (Location).
Interoperability Run - exercise session

Summary of the exercise session (run, or swim for the swimmers): where it took place, how long it lasted and how far the participant went.
Interoperability Run - heart rate

Heart rate measured by a wearable device during an Interoperability Run. Based on the FHIR core vital signs heart rate profile.
Interoperability Run - location

The run course or meeting point of an Interoperability Run (e.g. a seafront promenade near the meeting venue).
Interoperability Run - oxygen saturation (SpO2)

Peripheral oxygen saturation (SpO2) measured by a wearable device during an Interoperability Run. Based on the FHIR core vital signs oxygen saturation profile.
Interoperability Run - participant report

A report for one participant of an Interoperability Run, bringing together the vital signs, ECG, exercise session and environmental conditions, with a short (non-clinical) conclusion.
Interoperability Run - preventive care plan

A light preventive care plan for a runner: check vital signs before and after the run and join the scheduled run.
Interoperability Run - runner

A participant of the Interoperability Run. Inherits from the HL7 Europe Patient (EU core) profile, which requires a name and a birth date.
Interoperability Run - wearable device

A wearable device (smartwatch, chest strap, pulse oximeter, single-lead ECG) worn by the runner.

Structures: Extension Definitions

These define constraints on FHIR data types for systems conforming to this implementation guide.

Interoperability Run context

Links an observation to the Interoperability Run in which it was recorded: the event, its name and the measurement phase.

Terminology: Value Sets

These define sets of codes used by systems conforming to this implementation guide.

Interoperability Run - event types

All event types for an Interoperability Run.
Interoperability Run - measurement phases

All measurement phases for an Interoperability Run.
Interoperability Run - session types

Kinds of exercise session: run or swim.

Terminology: Code Systems

These define new code systems used by systems conforming to this implementation guide.

Interoperability Run - event type

The kind of community event at which an Interoperability Run takes place.
Interoperability Run - exercise codes

Codes for the run session and its measurements where no suitable LOINC code is used in this training IG.
Interoperability Run - measurement phase

When, relative to the run, a measurement was taken.
