Extension: Interoperability Run context

Official URL: https://example.org/ig/interoperabilityrun/StructureDefinition/irun-context Version: 0.1.0
Draft as of 2026-11-19 Computable Name: IRunContext

Links an observation to the Interoperability Run in which it was recorded: the event, its name and the measurement phase.

Context of Use

    This extension may be used on the following element(s)

    • Element ID: Observation

Usage info

Usages:

  • Use this Extension: Interoperability Run - ECG, Interoperability Run - environmental conditions, Interoperability Run - exercise session, Interoperability Run - heart rate and Interoperability Run - oxygen saturation (SpO2)
  • Examples for this Extension: Observation/ecg-post-run-example, Observation/environment-conditions-example, Observation/exercise-session-example, Observation/heart-rate-during-run-example... , Observation/heart-rate-pre-run-example and Observation/spo2-during-run-example

You can also check for usages in the FHIR IG Statistics
