Profiles

Profile Parent Main constraints
IRunRunner HL7 Europe patient-eu-core identifier (bib number) 1..*, name and birthDate required (from EU core)
IRunWearableDevice Device deviceName, type and patient required
IRunHeartRate FHIR core heartrate (vital signs) LOINC 8867-4, unit /min, run context, device required
IRunOxygenSaturation FHIR core oxygensat (vital signs) LOINC 2708-6, unit %, run context, device required
IRunECG Observation LOINC 11524-6, one component per lead with an MDC code and SampledData waveform
IRunExerciseSession Observation category activity; effectivePeriod required; code = run or swim session; components duration (LOINC 55411-3, min), distance (km), average pace (min/km); location via run context
IRunEnvironmentConditions Observation subject = course (Location); components air temperature (Cel), relative humidity (%), water temperature (Cel, for swimmers)
IRunReport DiagnosticReport subject = runner; results = HR, SpO2, ECG, session and conditions; conclusion; optional rendered form (PDF)
IRunLocation Location name required; address and position (coordinates)
IRunAppointment Appointment start and end required; participants sliced into runner and location
IRunPreventiveCarePlan CarePlan category preventive check-up; activities reference the run appointment and the planned measurements

The HL7 Europe base package (hl7.fhir.eu.base 2.0.1) does not define vital-sign profiles, so heart rate and SpO2 inherit from the FHIR core vital signs profiles, as required by FHIR for these measurements.

Terminology

  • LOINC for observation codes; UCUM for units.
  • ISO/IEEE 11073 MDC (urn:oid:2.16.840.1.113883.6.24) for ECG leads, e.g. 131329 = lead I.
  • Local code systems: event type, measurement phase and exercise codes (run / swim session, distance, average pace, air and water temperature, humidity, report, preventive check-up). These local codes could be replaced by LOINC / SNOMED CT codes in a later version.

Examples

  • Runner and smartwatch
  • Resting heart rate before the run
  • Heart rate during the run
  • SpO2 during the run
  • Single-lead ECG after the run
  • Run session (place, duration, distance)
  • Run course: Malaga seafront
  • Appointment for the run
  • Preventive care plan
  • Environmental conditions at the course
  • Participant report

Ideas for a Connectathon track

  • Client: convert data exported from a wearable vendor app into these profiles and POST them to a FHIR server.
  • Server / dashboard: search Observation?code=8867-4&subject=... and show results per phase and per event.
  • Validation: validate the instances against this IG (e.g. with Matchbox or the HL7 validator).

Acknowledgements

The exercise session, care plan, appointment and report, and the environmental conditions (air and water temperature, humidity), were added after feedback from participants of the Malaga Interoperability Run group.
